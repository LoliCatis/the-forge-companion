# Public data status

The first public snapshot includes only the first-party schema-compatible bootstrap pack 2026.10.17-bootstrap.1. It contains no ore, weapon, trait, probability, source, observation, or evidence records. Consequently, public builds begin with an empty catalog and show missing values as unavailable rather than substituting placeholder statistics.

Users can add entries manually or import a pack they are authorized to use. Private research tables, verification sessions, screenshots, evidence, and normalized observations are not included. Third-party source links are listed in DATA_SOURCES.md for reference only; redistribution rights have not been confirmed.
