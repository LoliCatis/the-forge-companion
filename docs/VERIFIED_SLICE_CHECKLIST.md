# Verification checklist

Use this checklist when a user imports a data pack or records a manual game observation. It describes workflow requirements only and contains no private game records.

| Step | Required check |
| --- | --- |
| Inspect | Confirm the entity, field, visible value, units, and session context from an authorized source. |
| Capture | Attach the original evidence file and verify its SHA-256. Preserve the original unedited. |
| Enter | Keep unknown or hidden fields unknown; do not infer from icons or incomplete text. |
| Review | Compare transcription with the original evidence and preserve earlier candidates. |
| Confirm | Only the user may confirm a capture; promotion requires the separate policy criteria. |
| Report | Summarize conflicts and unavailable fields without altering earlier observations. |
